# Pin/Star Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a client-owned pin/star to Sprint Hub task rows so the row's star and the "N件ピン留め" summary update together without a slots request.

**Architecture:** The server-mode Hub template already carries a per-row `done` state and a `done_count` fold. Add a per-row `pinned` Boolean and a top-level `pinned_count` Integer; the star is a checkbox with a presence binding, the star fill/row accent is CSS `:has`, and the summary is read after the loop. No server read, model, route, or new screen.

**Tech Stack:** Rails 8.1, Ruby 4.0.9, ReActionView 0.6.0, Herb 0.11.1, Minitest integration tests, plain CSS, Playwright capture outside the repo.

**Spec:** `docs/superpowers/specs/2026-10-28-pin-star-design.md`

## Global Constraints

- Client-owned state only. No DB column, migration, model, route, or persistence.
- No new screen. Add the feature to Sprint Hub (`/`).
- `pinned_count` is read **after** the loop. Do not put the count in a header before the list.
- Keep done and pin independent: the pin checkbox must not trigger the done `:has(input:checked)` styles, and done changes must not move `pinned_count`.
- Scope the existing done CSS to `.task-check input:checked`; add separate `.task-pin` rules.
- No custom JavaScript. The star/count update entirely through ReActionView's client state, presence binding, and count fold.
- Media capture uses the app's Japanese font stack (`Hiragino Sans`, `Noto Sans CJK JP`, `Meiryo`, `Yu Gothic`) and never falls back to a `system-ui`-only stack that resolves CJK to a Chinese face.
- D (Turbo comparison) is out of scope. The HTML twin sync is E, after A–C.
- Japanese prose in README/docs/commit messages goes through the yomiyasu skill.

## Review Focus

1. **Counted state before the loop**: `pinned_count` must be read after the task loop; a header read would fail to compile. The summary lives directly after the list.
2. **Done/pin CSS interference**: the existing `:has(input:checked)` rules must not match the pin checkbox; done styling and pin styling must remain independent.
3. **Count independence**: checking a pin must change only `pinned_count`; checking done must change only `done_count`.
4. **Zero requests**: toggling any pin must not send `?format=slots`; the browser probe records the request count.
5. **Media font**: the Hub stills/GIFs must render Japanese with the JP font stack, not the Chinese SC fallback.
