# 設計・実装計画の履歴

各画面を実装する前に書いた設計（`specs/`）と実装計画（`plans/`）を、日付順に残している。
現在の挙動と実測値は各画面のドキュメント（`docs/*.md`）と [`AGENTS.md`](../../AGENTS.md) が正で、
ここにある ReActionView / Herb のバージョンや見積もりは執筆時点のものだ。

設計と実装が食い違った箇所は、該当する設計または計画の冒頭に「実装時の裁定」として追記している
（すべての計画にあるわけではない）。
